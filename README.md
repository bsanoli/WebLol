# LoL — Worlds e Campeonato

Painel do time: estatísticas do Worlds 2026, planejador de comps e draft, mapa tático e conhecimento (objetivos e controle de wave).

**Como usar:** abra o link do GitHub Pages no Chrome ou no Edge, entre com seu Riot ID (nome#TAG) e escolha a pasta compartilhada **Time** do OneDrive do time.

Os dados do time (comps, jogadas, envios) não ficam neste repositório: ficam na pasta do OneDrive, com os envios criptografados para o admin e a versão oficial assinada.
