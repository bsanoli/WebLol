# Refatorar a interface

Localize a tela, o fluxo principal e os componentes envolvidos. Avalie a composição inteira, incluindo controles, conteúdo e seções vizinhas. Use a [skill de interface do WebLol](../weblol-ui/SKILL.md) para conhecer os padrões locais.

Escolha uma solução proporcional ao pedido. Para decisões de design com efeitos relevantes no uso, compare as alternativas, seus trade-offs e como validá-las. Em ajustes reversíveis, implemente a opção que melhor resolva o problema observado. Preserve as interações, dados e regras de negócio que a tela usa.

Confira a implementação em desktop com [visual-review](../visual-review/SKILL.md). Em pedidos de opinião, entregue propostas com evidências e prioridades.
